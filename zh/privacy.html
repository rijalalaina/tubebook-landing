01我们收集的信息

账户数据

  • 电子邮件地址、显示名称、密码哈希（或 OAuth 标识符）。
  • 账单数据——由 Stripe 处理；我们从不存储完整的卡号。

您提供的内容

  • 您提交处理的源材料：YouTube 链接、网页链接、粘贴的文本，以及上传的 Word、PowerPoint 或 PDF 文档。
  • 从您提供的网页链接中获取的文本。当您将网页添加为源时，我们会代表您获取该页面，并将其提取的文本与您的电子书一起存储，以便用于撰写章节。
  • 生成的电子书、封面、章节图片、有声书文件、翻译、编辑、质量检查结果及相关出版元数据。
  • 您上传的艺术作品以及您在书中放置图片的位置选择。
  • 您提供的写作样本，用于构建个人风格档案。上传的文件在读取后被删除；生成的风格描述和简短摘录会保留在您的档案中，以便您查看、修改或删除。
  • 主题研究查询。您在“查找主题”中输入的主题或利基，以及为其返回的结果，都会与您的账户关联存储，以便您无需再次付费即可重新打开研究。研究结果会被缓存，并可能被用来回答其他用户的等效查询——缓存记录仅包含主题和公开市场数据，绝不包含您的身份或任何源材料。

技术数据

  • IP地址、浏览器和设备信息、日志时间戳。
  • 使用事件（生成的开始、消耗的积分、错误）。

02我们如何使用信息

  • 运营服务：处理生成、交付导出、跟踪积分余额。
  • 通过Stripe进行订阅和积分包的计费。
  • 发送交易邮件（账户、账单、安全）。
  • 通过我们的邮件提供商（Brevo）向账户持有人发送偶尔的产品新闻和优惠。每封此类邮件都包含一键退订链接，立即且永久生效。
  • 调试、保护平台并提高质量。

03AI 处理与子处理方

为了生成、编辑、检查或翻译电子书，您的源和书籍的相关内容——视频转录、提取的网页或文档文本、粘贴的文本、章节文本和指令——会通过我们的服务器端集成发送给配置的AI模型提供商。这些提供商处理内容以返回请求的结果，并且根据适用的业务/API条款，不会使用API内容来训练他们的模型。

  • Supabase / Lovable Cloud——数据库、身份验证、存储。
  • Stripe——支付和订阅管理。
  • Cloudflare——托管、边缘运行时、DDoS 保护，以及用于章节插图和高级旁白的 AI 模型。
  • Google——Gemini 文本和图像生成（当选中或作为后备时）。
  • DeepSeek 和 Anthropic——当 TubeBook 配置时用于文本生成、编辑或质量审查。

有声书旁白

如果您为书籍配音，该书的文本会被发送到文本转语音提供商以便朗读。除此之外不会发送任何其他内容——没有姓名、电子邮件或账户标识符——提供商返回音频且不保留其任何权利。具体提供商取决于您选择的语音以及可用性：

  • Google Cloud Text-to-Speech——标准语音。
  • Cloudflare Workers AI（Deepgram Aura）——高级语音，在与托管应用相同的基础设施上处理。
  • OpenAI——仅作为后备，当您所选语音的提供商不可用时使用。根据 OpenAI 的 API 条款，此内容不用于训练他们的模型。

旁白是可选的，并且仅当您对特定书籍提出要求时才会运行。如果您不希望文本发送到语音提供商，请不要为该书生成旁白。

库存照片和用户作品

如果您选择库存照片，TubeBook 会将从书籍或章节主题派生的描述性搜索查询发送到一个或多个受支持的图库。它不会发送您的姓名、电子邮件或账户标识符。搜索结果可能包括提供商的图像标识符、摄影师姓名、来源 URL 和署名 URL；TubeBook 会将这些详细信息与所选图像一起存储，以便在编辑器和导出的书籍中包含所需的署名和链接。

  • Unsplash——库存照片搜索、其 API 指南要求的下载跟踪，以及关联的摄影师署名。
  • Pexels 和 Pixabay——库存照片搜索和来源署名（如可用）。

如果您上传自己的作品，文件将与书籍一起私密存储，仅用于您选择的封面或章节位置。您有责任确保拥有使用这些作品的权利。

主题研究

当您使用“查找主题”时，您输入的主题文本（及其派生短语）会被发送到以下服务以查找市场数据。您的姓名、电子邮件、账户标识符和源材料不会被发送——这些请求由我们的服务器发出，不携带任何识别您身份的信息。

  • Amazon——公开搜索建议服务，用于查看购物者输入的内容。
  • Google——公开搜索建议服务，用于相同目的。
  • Google Books API——用于统计和描述已出版的书籍。
  • YouTube Data API（Google）——用于查找候选源视频。
  • Serper——Google 搜索结果，用于查找候选源文章。

这些提供商中的每一个都可能根据其隐私政策记录收到的查询。由于查询是主题而非个人数据，并且在没有账户标识符的情况下发送，我们认为风险较低——但如果您不希望某个主题离开我们的系统，请不要将其输入“查找主题”。

出版风险检查

为了标记可能的知识产权风险，您书籍的标题、副标题、描述、关键词、类别和章节标题会被发送到上述相同的 AI 提供商。章节正文文本不会发送。

我们不会向商标注册服务发送任何内容。如果检查中提及品牌，TubeBook 会向您显示指向公共注册处的链接；是否点击由您决定，请求由您的浏览器发出，而非我们。

04数据保留

  • 生成的电子书保留30 天，然后归档/删除。请下载您想保留的任何内容。
  • 有声书旁白——无损母带及其衍生的所有内容——会在与其所属书籍相同的30 天期限内删除。音频不会比电子书保留更长时间。
  • 主题研究结果缓存14 天，之后同一利基将重新研究。您自己过去搜索的存储记录在您的账户中保持可用，直到您删除账户。
  • 账户和账单记录在您的账户活跃期间以及法律要求的时间内保留（通常最多7年，用于发票）。
  • 您可以随时请求删除您的账户（见第7节）。

05Cookie

我们使用严格必要的cookie进行身份验证和会话管理，并使用最少的分析cookie来了解产品使用情况。我们不运行第三方广告跟踪器。

06安全

我们在传输中使用TLS，静态加密，作用域数据库访问（行级安全），以及最小权限服务器凭据。没有系统是完美安全的；如果您认为您的账户已被入侵，请立即通过以下方式联系我们： support@tubebook.org.

07您的权利

根据您所在的司法管辖区（例如GDPR、CCPA），您对您的个人数据拥有以下权利：

访问您的数据
更正不准确之处
导出您的数据
删除您的账户
限制处理
反对处理

邮箱 support@tubebook.org 行使上述任何权利。我们会在30天内回复。

08国际传输

您的数据可能在美国和欧盟处理。如有需要，跨境传输将依据标准合同条款或同等保障措施。

09儿童

TubeBook不面向13岁以下儿童（欧洲经济区为16岁以下）。我们不会故意收集儿童数据。若发现此类数据，我们将立即删除相关账户。

10变更

我们可能更新本政策。重大变更将至少提前14天通过邮件或应用内通知告知。

11联系

隐私问题与数据请求： support@tubebook.org
